# gis

## 1.13. Понятие эталона. Отступы и классификация объектов качества

Учебная презентация для доклада на 15–20 минут. На примере нормального трафика и SYN-flood показаны выбор эталонов-медоидов, расчёт функциональных и геометрических отступов, линейная SVM с мягким зазором и поиск пограничных объектов.

Данные синтетические: 20 обучающих объектов и 8 специально подобранных проверочных примеров. Материалы демонстрируют метод и не являются оценкой качества реального сетевого детектора. Расстояние до границы интерпретируется как устойчивость текущего предсказания в выбранном пространстве признаков.

### Воспроизведение расчётов

Распакуйте архив, установите зависимости и запустите скрипт из папки с распакованными файлами:

```bash
python -m pip install -r requirements.txt
python build_example.py
```

Подробные определения признаков и формул приведены в `README.md` внутри архива. В презентации и тексте выступления указаны семь первоисточников и официальных документов.
