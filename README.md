# Эталоны и отступы в классификации трафика

Материалы по теме **1.13. Понятие эталона. Отступы и классификация объектов качества** для студентов информационной безопасности. Презентация: **23 слайда**, выступление на **15–20 минут**. Знания машинного обучения не требуются.

Сначала последовательно вводится вся теория: объект, признаки и класс → модель и обучение → определение эталона → расстояние и масштаб → выбор медоида → правило ближайшего эталона → отступ → линейная SVM и мягкий зазор → запас прочности и пограничные объекты. Это слайды 2–12.

Затем на слайдах 13–22 целиком разбирается **один пример с SYN-flood**: измеряем трафик, выбираем эталоны нормы и атаки, проверяем окно T07 по эталонам и SVM, считаем отступы восьми окон, выделяем пограничные случаи и показываем применение для аналитика ИБ. Слайд 23 — источники. Код и подробные вычисления доступны в Colab.

## Результат примера

Эталоны — медоиды `N05` (600 SYN/с, 15%) и `A06` (1300 SYN/с, 65%). Нормальное окно `T07` (1200 SYN/с, 16%) ближайший эталон ошибочно относит к атаке; SVM на той же обучающей выборке относит его к норме. Это иллюстрация ограничения одного образца, а не доказательство превосходства SVM вообще.

При пороге расстояния `r < 0.10` перепроверку получают `T03–T06`. Внутри этой группы `T04` — пропуск атаки, `T05` — ложная тревога. Расстояние до границы означает запас сохранения текущего ответа, а не вероятность или гарантию правильности. Отступ для эталонов и геометрический отступ SVM определены по-разному; напрямую сравнивать их величины нельзя.

Все 20 обучающих и 8 специально выбранных проверочных окон синтетические. Они объясняют метод, но не оценивают качество реального детектора. В примере нет запуска атаки, внедрения или автоматической блокировки. Прогноз атаки формирует сигнал при любом запасе; малый запас отдельно назначает перепроверку при любом прогнозе.

Восемь источников включают оригинальную работу по SVM, Stanford CS229, публикацию о медоидах, RFC 4987, документацию scikit-learn и NIST SP 800-94. CICDDoS2019 указан как возможный источник данных для дальнейшей проверки и в расчётах не использован.
