Компания и спикер в материалах оставлены нейтральными. Новая презентация
`work/3cx-new/` проводит один кейс через восемь слайдов: вопрос, самостоятельное

## Исследования и исходники

- `work/`: первичные исследования Luna Moth, документация сервисов, изученные
  выступления, брифы, черновики, финальная речь, генераторы документов и презентации.
- `work/3cx-new/`: новая презентация, речь, три демокадра, PNG слайдов и архив.
  В `source/` находятся генераторы, текст речи, зависимости и шаблон документа.
- `work/3cx/`: исследования кейса и сервисов, проверенные редакторские основания,
  брифы, текст и генераторы самостоятельного доклада.
- `work/deck_preview/`: PNG всех 16 слайдов; `work/deck_contact_sheet.png` — общий вид.
- `work/reference.docx`: шаблон оформления документов.
- `work/ti-downloads/dist/`: статическая страница с просмотром презентации,
  отдельной страницей 3CX и всеми необходимыми файлами для скачивания.

Для просмотра страницы из этой папки:

```sh
python -m http.server 8000 --directory work/ti-downloads/dist
```

Затем открыть `http://localhost:8000/` или `http://localhost:8000/3cx/`.

Генераторы сохранены в исходном виде: некоторые используют абсолютные пути
`/workspace/work`, Pandoc, LibreOffice и установленные в окружении шрифты.
Для повторной генерации в другом окружении пути и зависимости потребуется настроить.
`publish_source.py` — архивный помощник публикации исходной страницы через Sites;
токены он получает во время запуска, сохранённых токенов в файле нет.

## Состав и целостность

`MANIFEST.json` перечисляет 121 файлов материалов с размером и SHA-256.
`MANIFEST.sha256` позволяет проверить эти файлы и сопровождающую документацию:

```sh
sha256sum -c MANIFEST.sha256
```

Копии документов и изображений внутри `dist/` сохранены, чтобы относительные
ссылки и скачивания страницы работали. В комплект не включены Git-метаданные,
профили LibreOffice, временные тесты экспорта, проверочные снимки страниц,
служебные результаты публикации, архив развёртывания и привязка к Sites.
