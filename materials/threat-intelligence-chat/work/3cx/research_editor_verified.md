# Дополнительные сведения, проверенные редактором

Проверка 14 октября 2026. Это уточнение выбора объектов для финального доклада; оно заменяет рекомендацию пары pbxphonenetwork/89.45.67.160 из первоначальных рабочих заметок. Для единой Windows-линии выбрана другая пара.

## Сетевой пример Windows

Первоисточник: [Unit 42 — Threat Brief: 3CXDesktopApp Supply Chain Attack](https://unit42.paloaltonetworks.com/3cxdesktopapp-supply-chain-attack/), опубликованный разбор 2023, доступный текст прочитан.

Раздел Windows, таблица 1: у файла `icon13.ico` указан SHA-256 `4e08e4ffc699e0a1de4a5225a0b4920933fbb9cf123cde33e1674fde6d61444f`, извлечённый C2 URL — `hxxps://msedgepackageinfo[.]com/microsoft-edge`. Роль иконочных файлов — получение адреса следующего сетевого шага, а не запуск картинки пользователем. Известный путь к репозиторию: `raw.githubusercontent[.]com/IconStorages/images/main/icon[1-15].ico`. Сам репозиторий и исходные C2 адреса не посещались.

Не требуется показывать хеш ICO: основное демо остаётся по SHA-256 конкретного ffmpeg.dll из Sophos CSV. Не утверждать, что именно выбранный экземпляр DLL обязательно получил icon13 или обращался к определённому IP. Здесь это опубликованный сетевой пример Windows-кампании, не результаты нашего хоста.

## Датированная историческая DNS-связь

Первоисточник: [Mandiant — 3CX Software Supply Chain Compromise](https://cloud.google.com/blog/topics/threat-intelligence/3cx-software-supply-chain-compromise), 20 апреля 2023, доступный текст и таблица 3 прочитаны.

Таблица 3: `msedgepackageinfo[.]com` → `185.38.151[.]11`, дата разрешения **9 января 2023**. Контекст таблицы — слабое пересечение инфраструктуры разных кластеров активности; нельзя выдавать общее размещение за доказательство единого оператора. Дата не относится к нашему учебному событию и не доказывает тот же IP для домена на любую дату марта. Текущий DNS и владелец не проверены.

Эта пара позволяет показать роль AbuseIPDB без случайного адреса. Текущую карточку, score и жалобы финальный доклад не заявляет. Проверка жалоб в 2026 году не восстанавливает репутацию IP в марте 2023. Основной вопрос для компании — фактические домен/URL/IP в её собственном сетевом событии и время связи.

## Принятые рамки

- Основная история — Windows; не переносить на неё macOS-путь с pbxphonenetwork.
- Хронология реального кейса и события учебной организации разделены.
- Поиск точного известного хеша в истории — поиск IoC, а не вся программа hunting.
- Hunting проверяет гипотезу о необычных сетевых действиях легитимного клиента после изменения его комплекта; кандидаты требуют проверки обновлений и назначения ресурса.
- Для исторического упражнения нужно явно выбрать архив марта–апреля 2023. При отсутствии таких данных нельзя заявлять, что последовательность не существовала. Для другого актуального события период выбирают по нему, а не по старому кейсу.
