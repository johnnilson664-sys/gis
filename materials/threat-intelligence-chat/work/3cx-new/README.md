# Думать с помощью TI: новая презентация 3CX

8 слайдов,25 минут, полная речь в заметкахPowerPoint. Компания и спикер оставлены
нейтральными. Основной формат — готовые кадры; живая демонстрация по возможности.

- `3cx_ti_presentation.pptx`: редактируемая презентация, схемы и полная речь в заметках.
- `3cx_ti_presentation.pdf`: восемь слайдов для просмотра и показа.
- `3cx_speaker_notes.docx`: речь, сценарий демонстрации и источники.
- `3cx_speaker_notes.md`: отдельная речь для репетиции.
- `demo_guide.md`: готовый и живой варианты на 1:30, вопросы и памятка.
- `demo/`: три подготовленных аналитических кадра, не скриншоты текущих карточек.
- `slides/`: PNG всех восьми слайдов.
- `sources.md`, `timing.json`: источники и расчёт времени.
- `source/`: исходники генерации и шаблон документа. Доступны Python-зависимости,
  для экспорта также нужныPandoc,LibreOffice и шрифтыDejaVuSans.

Сюжет: учебное предупреждение после обновления → задачаTI → точный объект →
основания и время → обогащение вVirusTotal/AbuseIPDB → опубликованный компонент 3CX →
внутренние проверки → следующий шаг. Исторические факты отделены от учебной ситуации.
Текущие показатели сервисов и результаты внутреннего расследования не придуманы.

## Повторная генерация

В папкеsource: установить зависимости изrequirements.txt, выполнитьbuild_deck.py,
затемmake_materials.py. Экспортировать созданныйPPTX вPDF черезLibreOffice;
после этогоrender_deck.py создаётPNG. Генераторы материалов используют относительные
пути внутриsource. Сценарии публикации и служебные данныеSites в архив не включены.

Дата подготовки:21 октября 2026. Расчётный хронометраж требует репетиции с паузами.
